FNV Decomp instalation:

1. download and install APK
2. inside of data/ folder create folder "fnv_vita"
3. create a folder inside of fnv_vita and name it "data"
4. inside of data folder insert the:
fallout - meshes.bsa
fallout - sound.bsa
fallout - Textures.bsa
fallout - Textures2.bsa
falloutnv.esm

now you can launch the game
